### 🎬 Featured tool: Paper Cut Studio

**[Paper Cut Studio](https://github.com/pa1potluri/papercut-studio)** turns a folder of layered PNGs into a moving paper-cut / diorama shot. You direct the motion yourself.

- **A slider for every layer.** Each layer gets a default motion from its file name (`moon` glows, `fire` flickers, `tree` sways, `rider` walks), and you can override any of it.
- **Camera moves:** push in, pull out, and pan, with paper-depth parallax.
- **Extras:** soft glow, twinkle, snow and paper edge shadows.
- **What you see is what you render.** The browser preview matches the MP4 frame for frame.
- **Batch mode:** render many folders from the command line, no UI needed.

```bash
git clone https://github.com/pa1potluri/papercut-studio
cd papercut-studio
pip install -r requirements.txt
python papercut_studio.py
```

Runs on Windows, macOS and Linux with Python 3.10+.

## Hi, I'm Pavan Potluri

VFX supervisor with **20 years in film**. Compositing veteran (Nuke).
These days I build small, free tools that give artists back the control that auto-AI tools take away.

**What I believe:** the artist should drive the shot. Tools should show you a live preview and give you sliders, not a single "generate" button and a prayer.

---

### Free tools

| Tool | What it does |
|---|---|
| [**Paper Cut Studio**](https://github.com/pa1potluri/papercut-studio) | Layered PNGs to a moving paper-cut / diorama shot. Live preview, a slider per layer, parallax camera, MP4 render. |

More tools are on the way: VFX tips, small pipeline helpers and free web tools.

| Tool | What it does |
|---|---|
| [**Paper Cut Studio**](https://github.com/pa1potluri/papercut-studio) | Layered PNGs to a moving paper-cut / diorama shot. Live preview, a slider per layer, parallax camera, MP4 render. |
| **RPM Studio** *(coming soon)* | A full song pipeline: compose, mix sections, depth mix, narration, lyric subtitles, remaster. |
